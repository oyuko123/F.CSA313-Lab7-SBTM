## Төслийн тухай

Энэхүү лабораториор Session-Based Test Management (SBTM)
аргыг ашиглан «Уншлагын жагсаалт» вэб аппын чанарыг шалгана.

## Файлын бүтэц

- `charter.md` — тестийн төлөвлөгөө
- `session-report.md` — exploratory session-ийн тэмдэглэл
- `bugs/` — согогийн тайлангууд
- `evidence/` — API тестийн нотолгоо
- `screenshots/` — согогийн дэлгэцийн зураг

## Дүгнэлт

Энэхүү лабораторийн ажлаар SBTM аргыг ашиглан уншлагын жагсаалтын аппад exploratory testing хийв.

- **Хамгийн үр дүнтэй аялал:** Supermodel аялал нь ном нэмэх, хайх, устгах зэрэг үндсэн үйлдлүүдийн согогийг илрүүлэхэд үр дүнтэй байв.
- **Couch Potato аялал:** Хоосон талбар болон он жилийн захын утгуудыг шалгахад оролтын баталгаажуулалтын асуудлууд илэрсэн.
- **Saboteur аялал:** Буруу JSON өгөгдөл илгээхэд API `400 Bad Request`-ийн оронд `200 OK` буцааж байгааг илрүүлэв.
- **Илэрсэн согогууд:** Нийт номын тоолуурын зөрүү, хоосон өгөгдөл зөвшөөрөх, он жилийн хязгаар шалгахгүй байх, том жижиг үсэг ялгадаг хайлт, буруу JSON-ийг зөвшөөрөх, давхардсан ном нэмэх, устгах товчны өнгөний зөрчил гэсэн 7 асуудлыг баримтжуулав.
- **Автомат тестээр шалгаж болох зүйлс:** Оролтын баталгаажуулалт, он жилийн хязгаар, давхардал, хайлтын үр дүн, API-ийн HTTP статус болон тоолуурын зөв эсэхийг автомат тестээр шалгаж болно.
- **Хүний ажиглалтаар шалгах зүйлс:** Товчны өнгө, мессежийн ойлгомжтой байдал, урт гарчигтай үеийн хүснэгтийн харагдах байдлыг UI дээр гараар шалгах нь ач холбогдолтой.
- **Цаашид шалгах зүйлс:** Давхардлыг зохицуулах дүрэм, хайлтын хоосон үр дүнгийн мессеж, маш урт зохиолчийн нэр, тусгай тэмдэгт, API-ийн бусад буруу хүсэлтүүдийг нэмэлтээр турших шаардлагатай.
