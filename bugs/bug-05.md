# BUG-05: Буруу JSON хүсэлтэд API 200 OK буцааж байна

**Орчин:** Уншлагын жагсаалт v2.0, Ubuntu Linux (WSL2), Node.js v22.22.1, 2026-10-18

**Урьдчилсан нөхцөл:** `node app.js` серверийг шинээр асаасан.

## Дахин гаргах алхам

1. Терминал нээнэ.
2. `node app.js` ажиллаж байгааг шалгана.
3. Дараах хүсэлтийг илгээнэ:

   ```bash
   curl -sS -i -X POST http://localhost:3000/api/books \
     -H 'Content-Type: application/json' \
     -d 'буруу оролт'
   ```

4. HTTP статусын мөр болон response body-г шалгана.

## Хүлээгдэж байсан

Буруу JSON биетэй POST хүсэлтэд сервер `400 Bad Request` буцаах ёстой.

## Бодит үр дүн

Сервер `HTTP/1.1 200 OK` буцааж, `{"result":"OK"}` гэсэн response body өгсөн.

## Ноцтой байдал

**Major** — буруу форматтай хүсэлт амжилттай боловсруулагдсан мэт хариу авч, API хэрэглэгчийг төөрөгдүүлж болзошгүй.
